目标场景和背景说明

1、核心目标是将处理流相关业务作为独立应用开发，降低与决策系统的耦合度，提升维护与开发效率。


功能说明

【处理流管理】用于创建、编辑、删除处理流，配置处理流分类、调用接口及入参，具体功能包括：

处理流基础管理：支持处理流的增删改查，配置处理流名称、分类、状态、调用接口等基础信息。

入参配置：定义处理流所需参数，设置参数名称、key、类型及说明。

处理流列表展示：显示处理流名称、分类、调用接口、创建时间等信息，支持查询、排序与操作。

状态控制：启用或停用处理流，控制其是否可被决策触发。


字典说明：选自系统配置->字典管理

1. 处理流分类

分类名称     说明

发送短信     触发后向指定用户发送短信通知

数据库操作     对数据库执行增删改查操作

加入代办     将任务添加至用户待办事项

发送邮件     向指定邮箱发送邮件

调用接口     调用外部系统接口

加入风险库     将风险数据添加到风险数据库

写入文件日志     将处理结果写入文件日志

2. 处理流状态

状态     说明

启用     处理流可被决策正常触发

停用     处理流不可被触发


权限说明

操作权限：

管理员：可创建、编辑、删除所有处理流，配置入参及状态。

普通用户：可查看权限内的处理流，无法修改配置。

页面权限：按需配置。


数据说明

1. 处理流基础数据

字段名称     说明     约束 / 规则

处理流名称     处理流唯一标识     必填

处理流分类     所属操作类型     从处理流分类字典选择，必填

调用接口     处理流执行的接口地址     格式为 URL，必填

创建时间     处理流创建时间     系统自动生成，只读

更新时间     处理流最后修改时间     系统自动生成，只读

创建人     处理流创建者     系统自动关联，只读

状态     处理流当前状态     从处理流状态字典选择，默认启用

2. 处理流入参数据

字段名称     说明     约束 / 规则

参数名称     参数显示名称     中文描述，必填

参数 key     参数唯一标识     由英文、数字、下划线组成，必填

参数类型     参数数据类型     如字符串、数字、日期等，必填

参数说明     参数用途描述     选填

是否必填     参数是否为必填项     默认必填


交互说明

查询

处理流列表查询：

下拉框筛选处理流分类（发送短信、数据库操作等），自动触发查询。

文本框搜索处理流名称，支持模糊查询，自动触发查询。

表头支持按【处理流名称、处理流分类、调用接口、创建人、状态】查询。

表头支持按【创建时间、更新时间、处理流分类、状态】排序。


排序

表头支持排序字段：【排序、创建时间、更新时间、状态、应用类型】


表格更新

状态修改：状态改变触发更新请求，请求过程中禁用开关,请求结束后解禁，修改失败，状态恢复修改之前的。


新增 / 编辑处理流

必填字段校验：

处理流名称、分类、调用接口、至少一个入参为必填项，未填写时表单无法提交。

调用接口需符合 URL 格式，否则提示错误。

参数 key 需由英文、数字、下划线组成，否则提示错误。

参数管理：

支持添加多个入参，点击 “添加” 按钮新增参数行。

可删除已添加的参数，点击 “删除” 按钮移除对应参数。

提交与验证：

点击 “提交” 按钮后，前端验证所有字段格式，通过后发送请求至后端。

后端接收到请求后，验证调用接口的有效性（如接口是否可访问）。

验证成功则保存处理流配置，失败则返回错误原因（如接口地址无效、参数类型错误等），提示用户修改。


提交

点击 “提交” 按钮后，前端验证所有字段格式，通过后发送请求至后端,按钮加载状态，拿到结果后解除，成功关闭窗口失败保持窗口，告知原因，方便用户修改。


危险操作

删除处理流：弹出确认弹框，提示 “删除后处理流及关联数据无法恢复，是否继续？”，确认后执行删除操作。


其他交互

无特殊情况，按原型开发即可不做任何说明。
