目标场景和背景说明

1、为识别哪些款项类型是社保商保待遇款，提专员款项处理效率，需对银行流水款项进行待遇款与非待遇款的精准标记，确保待遇款数据可追溯、可统计，满足业务分析需求。

2、系统需支持款项状态流转（未标记→已标记）、收款截图管理（未上传→已上传）、认领状态关联（未认领 / 部分认领可标记，已认领不可标记），实现款项全生命周期的可视化管理。


功能说明

【款项标记管理】用于实现款项类型标记（待遇款 / 非待遇款）、收款截图管理、认领状态关联及相关查询统计功能，核心功能包括：

款项状态标记：对未标记款项标记为待遇款（含具体类型）或非待遇款，对已标记款项支持重新标记。

收款截图管理：跟踪收款截图上传状态，支持发送上传提醒邮件。

认领状态关联：根据款项认领状态限制标记操作权限（已认领款项不可标记）。

多条件查询与统计：支持按收款方、付款方、状态、款项类型等维度查询款项数据。



字典说明：

1. 款项类型

待遇款：含具体子类型，包括社保、养老、医疗、雇主险等，需关联业务核算需求。

非待遇款：除待遇款外的其他款项类型，无需关联待遇核算。

2. 款项状态

未标记：款项导入后未经过专员判断，需执行标记操作。

已标记：专员已完成判断并标记款项类型，支持重新标记。

3. 收款截图状态

未上传：未收到公司收款回单截图，可手动触发邮件提醒上传。

已上传：已收到并存储公司收款回单截图，支持查看。

4. 认领状态

未认领：款项未被任何业务关联认领，可执行标记操作。

已认领：款项已关联具体业务完成认领，不可执行标记操作。

部分认领：款项部分金额被关联认领，可执行标记操作。


权限说明

操作权限：仅专员及超级管理员有权限进入本页面并执行所有操作（标记、上传截图、发送邮件等）。

特殊限制：已认领状态的款项，所有角色均不可执行标记操作。


数据说明

已认领金额：取自待遇下发认领记录中的已认领金额，实时同步更新。

未认领金额：= 款项总金额 - 已认领金额，自动计算生成。

标记时间：取当前专员执行标记操作的系统时间，精确到秒。

标记人：取当前执行标记操作的用户账号（姓名）。

款项状态更新时间：取最近一次标记操作的系统时间，用于排序和追踪。

交互说明

查询

自动触发条件：下拉框选项改变时自动触发查询；文本框输入内容后回车自动触发查询，减少用户点击操作。

表头支持查询字段：【收款方名称、收款方账号、付款方名称、付款方账号、流水号、状态（未标记 / 已标记）、款项类型（待遇款 / 非待遇款）、收款截图状态（未上传 / 已上传）、认领状态（未认领 / 已认领 / 部分认领）、交易时间（区间）】。

排序

表头支持排序字段：【交易时间、金额、标记时间、认领状态】，点击表头字段切换升序 / 降序。

默认排序：交易时间、倒序


表格更新

状态修改（标记操作）

未标记→已标记：点击 “标记待遇款类型” 或 “标记为非待遇款” 按钮触发操作。

二次确认：标记为非待遇款时弹出确认弹窗（内容：“确认为非待遇款，确认操作？”），点击 “确定” 执行，“取消” 终止。

请求处理：操作触发后按钮显示加载状态，请求过程中禁用当前行操作按钮；请求成功则更新状态为 “已标记” 并刷新表格，失败则保留原状态并提示失败原因（如 “网络异常，请重试”）。

特殊限制：系统检测到认领状态为 “已认领” 时，“标记待遇款类型” 和 “标记为非待遇款” 按钮隐藏。

收款截图管理

未上传状态：点击 “发送要求上传公司收款截图邮件” 按钮，触发邮件发送请求，请求成功提示 “邮件已发送”，失败提示 “发送失败，请检查邮箱配置”，发送的邮件格式：

主题：请补充收款公司回单截图（请及时处理）

····

财务同学，您好：

      为便于专员识别是否为待遇款，请您尽快补充以下流水的收款公司回单截图，并上传至系统。

上传路径：财务管理 → 到款流水。

需上传流水清单：

ID，金额，流水号（表格形式）


👉 请尽快处理，感谢您的支持！

祝好。


              专员：xxx

              2025年8月5日 17:20（系统自动填写当前时间）

····

状态联动：上传截图后，系统自动更新 “收款截图状态” 为 “已上传”，同时以站内信的形式通知对应专员（发出邮件的专员）“xxx,您要求的收款截图已上传，请前往：待遇管理-》到款流水处理。”，支持点击查看截图详情。

标记待遇款类型弹窗

字段填写：弹窗内展示当前款项基本信息（收款方、付款方、金额等），需选择具体待遇款子类型（社保 / 养老 / 医疗等），下拉框选项必选。

提交交互：点击 “提交” 按钮后前端验证必选字段，通过后发送请求，按钮显示加载状态；请求成功关闭弹窗并刷新表格，失败保留弹窗并提示原因（如 “请选择款项子类型”）。

取消操作：点击 “取消” 按钮或关闭弹窗，放弃标记操作，状态保持不变。
