接口管理需求说明

业务说明


产品说明书

https://ycnfozkwomo9.feishu.cn/docx/I3JPd8MR9oUNqEx4Oj3c5f4Kn3g?from=from_copylink


目标场景和背景说明

1、为数据分析平台的 BI 工具与报表系统提供标准化接口管理能力，实现数据对接的规范化与集中化，减少各业务系统与数据分析平台的耦合度。

2、支持开发者无限扩展接口类型与功能，开发者通过底层服务 API 调用接口时，只需专注于业务逻辑，无需重复处理接口连接与数据格式转换等细节。例如，BI 工具调用 “获取用户列表” 接口进行人员数据分析，报表系统调用 “获取字典列表” 接口获取基础数据字典，均通过统一的接口管理平台实现。


功能说明

【接口管理】用于管理数据分析平台 BI 与报表系统所需接口的创建、编辑、删除、查询、状态管理等操作。


字典说明

1、 接口状态

启用：默认状态，接口可被 BI 工具与报表系统正常调用。

停用：停用的接口无法被平台调用，需启用后才可使用。

2、请求方法

GET     用于获取资源数据，安全且幂等

POST     用于创建新资源，非幂等

PUT     用于更新资源，幂等

PATCH     用于部分更新资源，幂等

DELETE     用于删除资源，幂等

HEAD     用于获取资源头部信息，安全且幂等


权限说明

操作权限：设置接口的增删改查操作权限，不同角色（如管理员、数据分析师）拥有不同权限。例如，管理员可创建与删除接口，数据分析师仅可查看与调用接口。

页面权限：能进入接口管理页面的用户，根据其角色权限执行相应操作，确保接口配置的安全性。


数据说明

接口名称：数据唯一，用于标识接口，便于用户识别，如 “获取用户部门”“获取字典列表”。

接口分类：必填项，从预设分类中选择，确保接口功能归类清晰。

请求方法：必填项，从 GET、POST、PUT、PATCH、DELETE、HEAD 中选择，明确接口的操作类型。

接口地址：必填项，格式为 URL，用于指定接口的访问路径，如/api/user/list。

查询字段：

    字段名：必填项，由英文、数字、下划线组成，如keyword page_size。

    字段类型：必填项，包括字符串、数字、布尔等，定义接口参数的数据类型。

    是否必填：标识该字段在接口调用时是否为必填项，确保数据完整性。

    字段说明：对字段的用途进行简要说明，如 “查询关键字”“分页大小，默认 20”。

创建时间 / 更新时间：自动记录接口的创建与更新时间，用于版本追溯。

创建人：记录创建接口的用户信息，便于责任追溯。


交互说明

查询

筛选下拉框：

选项包括接口分类（如公共接口、人事服务等），选择不同分类时自动触发查询。

新增筛选条件（状态：启用 / 停用），方便用户快速定位接口。

搜索框：

输入接口名称后按回车自动触发搜索，支持模糊查询。

搜索结果实时显示在接口列表中。


排序

表头支持排序字段：【创建时间、更新时间、接口名称、状态、接口分类】，用户可点击表头按升序或降序排列。


表格更新

状态修改：

状态改变触发更新请求，请求过程中禁用开关，请求结束后解禁，修改失败则状态恢复修改前。


新增 / 编辑接口

必填字段校验：

接口名称、接口分类、请求方法、接口地址为必填项，未填写时表单无法提交。

接口地址需符合 URL 格式，否则提示错误。

查询字段的字段名需由英文、数字、下划线组成，否则提示错误。

默认值填充：

请求方法默认选中 GET，状态默认选中 “启用”。

接口分类下拉框：

显示所有支持的接口分类，用户根据实际接口功能选择。

查询字段管理：

支持添加多个查询字段，点击 “添加” 按钮新增字段行。

可删除已添加的查询字段，点击 “删除” 按钮移除对应字段。

提交与验证：

点击 “提交” 按钮后，前端验证所有字段格式，通过后发送请求至后端,按钮加载状态，拿到结果后解除，成功关闭窗口失败保持窗口，告知原因，方便用户修改。

后端接收到请求后，验证接口地址的有效性（如是否可访问）。

验证成功则保存接口配置，失败则返回错误原因（如接口地址无效、字段类型错误等），提示用户修改。


删除操作

危险操作确认：删除接口时弹出确认弹框，提示 “删除后将无法恢复，且可能影响 BI 工具与报表系统使用，是否继续？”，避免误操作。

关联检查：删除前检查接口是否被 BI 工具或报表系统引用，若有引用则提示无法删除，需先解除引用关系。
